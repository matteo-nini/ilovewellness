# @ilovewellness/mobile

App iOS/Android di ILoveWellness con **Expo SDK 57** (React Native + Expo Router).
Stesse funzioni lato cliente del sito: esplora, scheda operatore, prenotazione, le mie prenotazioni, profilo.

```bash
pnpm dev:mobile                         # dalla radice: QR code per Expo Go
pnpm --filter @ilovewellness/mobile export:web   # versione web statica in dist/
```

Guida completa (concetti, prova sul telefono, come mostrarla ad altri): [docs/11-app-mobile.md](../../docs/11-app-mobile.md).
